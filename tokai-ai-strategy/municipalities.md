# 東海4県・全160市町村 AI時代の産業構造マップ（仮説）

> 前提仮説：**「フィジカルAI × HaaS（Hardware as a Service）」により、東海の第一次・第二次産業がそのまま高付加価値の第三次産業へスライドし、東京のGDPに迫る／超える。**
> 本書はその仮説を市町村レベルまで落とし込み、「各自治体が何で稼ぐ地域になるか」「地銀はどこに資金を入れるべきか」を整理したもの。
> 現在の基盤欄は公知の産業集積・企業立地に基づく定性整理であり、数値は含まない。検証は末尾の「データでの検証方法」を参照。

対象：愛知県54・岐阜県42・三重県29・静岡県35　＝ **160市町村**

**構造的な示唆**
1. **稼ぐ力の源泉は「⚙️HaaS×🧠頭脳」の西三河〜名古屋〜浜松ライン**。ここでのサービス化比率が上がるかどうかが東京逆転の成否を決める。
2. **🧱素材と⚡エネルギーは「AIの物理的なボトルネック」**。大垣・四日市・東濃・碧南・知多は、AI需要が増えるほど価格決定力を持つ。

## 6. データでの検証方法

この表は仮説であり、以下のデータで市町村ごとに検証すべきである。

| 検証したいこと | データソース |
|---|---|
| 市町村別の産業構造（1次/2次/3次の比率） | 各県の市町村民経済計算、RESAS（地域経済分析システム） |
| 業種別の事業所数・従業者数・付加価値 | 経済センサス‐活動調査 |
| 製造品出荷額 | 経済構造実態調査（旧工業統計） |
| 農業産出額 | 市町村別農業産出額（推計） |
| 観光入込・宿泊 | 各県観光統計、宿泊旅行統計調査 |
| 地域内の資金循環・域外流出 | RESAS「地域経済循環分析」 |
| ソフトウェア人材の流入 | 国勢調査（職業別）、求人倍率 |

**次の一手としておすすめ**：まず RESAS の「地域経済循環図」で160市町村の「域外から稼ぐ産業」を抽出し、本表の類型と突き合わせる。類型と実データが一致しない自治体こそ、地銀にとっての「未開拓の投資機会」か「仮説の修正点」になる。
