# ジンジブ様_CoreUniq オンボーディング・POC 資料（Givin' Back フォーマット版）

Drive 上の以下2ファイルを読み込み、Givin' Back の標準資料フォーマットに合わせて作り直したもの。

- 元スライド: `ジンジブ様_CoreUniqオンボーディング・POC資料.pptx`（Walnut Exporter 出力）
- 元ドキュメント: `ジンジブ様_CoreUniqオンボーディング・POC資料`（アジェンダ／スライド構成案）

## フォーマットの基準

`【中発販売様】CoreUniqサービス説明資料` など既存の Givin' Back 資料から抽出。

| 要素 | 仕様 |
| --- | --- |
| スライドサイズ | 16:9（13.333 × 7.5 inch） |
| 基調色 | ネイビー `#144B7F` / 濃ネイビー `#0E355C` |
| アクセント | コーラル `#F96167` / 淡ピンク `#FDECED` |
| 面・罫線 | 淡ブルー `#EEF3F8` / 罫線 `#D8E0EA` |
| 文字 | 本文 `#1E293B`、補足 `#6B7787`、フッター `#939EAC` |
| フォント | Meiryo（欧文・和文とも） |
| ヘッダー | 左に見出し（ネイビー太字21pt）、右上に Givin' Back ロゴ、下に罫線 |
| リード | コーラルの縦バー＋ネイビー太字14.5pt |
| フッター | 罫線＋ `© Givin' Back Inc. All Rights Reserved. | Confidential` ＋ ページ番号 |
| 表紙・裏表紙 | ネイビー→コーラルのグラデーション全面、白ロゴ・白文字 |

元スライドで使われていたオレンジ系（`#F7941D` / `#F2D4AA` / `#FFF3E2`）は Givin' Back の
カラーではないため、すべてネイビー×コーラルに置き換えている。

## 生成方法

```
pip install python-pptx pillow
python3 build_deck.py
```

`build_deck.py` を編集して再実行すれば pptx を作り直せる。ロゴ素材は Drive の
「Givin' Backロゴ」から切り出したもの（`logo_gb.png` / 白版 `logo_gb_white.png`、
ヘッダー用横組み `lock.png` / `lockw.png`）。
