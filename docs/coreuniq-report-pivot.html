書き方に必ず注意が要る箇所

  • 第4章の1点目（推進担当の不在）は、書き方を必ず西内様に確認してください。個人の健康に関する事柄です。報告書には「推進担当者が長期不在となる期間があった」程度に留め、理由や期間の詳細は書かないのが原則です。本人が復帰される前に、本人の不在を材料として報告書に載せることになるため、中屋敷様・西内様の了解を取ってから書くべき箇所です。
  • 第4章の3点目・4点目（水野チームの階層／石田チームは不要だった）は、個人の力量の話に読まれないよう、必ず「組織構造」「部署特性」として書く。アンケートM2の回答をそのまま根拠に引くと、事実として読ませやすくなります。
  • 第5章Aの「判断がつかない手探り」は、西内様ご自身の言葉（M4）を引用する形にする。外部が指摘する形にすると角が立ちます。
