### zip-renamer.html

メール添付まわりの作業をブラウザだけで完結させるツール（サーバ送信なし）。

- **パスワード付きZIPを作る** … ファイル／フォルダを選んでパスワードを設定
  - 暗号化方式は **ZipCrypto**（Windows・macOS の標準機能で開ける／強度は低め）と **AES-256**（強固／展開に 7-Zip 等が必要）から選択
  - 既存のZIPを選んだ場合は、入れ子にせず中身をそのまま暗号化して詰め直し
  - 出力は `.zip` / `.zi_` を選択可能
- **拡張子を変える** … 中身はそのままで `.zip` ⇄ `.zi_` を付け替え
- **保存先の指定** … Chrome・Edge などでは保存ダイアログや保存先フォルダを指定でき、
  フォルダを選ぶとダウンロードを経由せず直接書き出す（非対応ブラウザではダウンロードフォルダに保存）
